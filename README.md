# iptv_tivimate

A playlist (`pwg.m3u`) and an XMLTV guide (`guide.xml`) for IPTV players such as TiviMate.

- Everything here comes from freely and publicly accessible sources: the channel list from
  the [iptv-org](https://github.com/iptv-org/iptv) project and the guide data from public
  EPG feeds.
- This repository hosts no video. The playlist only contains links to streams that third
  parties publish openly on the internet. Nothing is re-hosted, re-streamed, recorded or
  modified.
- The files are **not updated on a regular basis**. Links stop working, channels change and
  guide data goes stale. There is no schedule and no support.
- Provided as-is, for personal and educational use, without any warranty. Check the laws of
  your country and the terms of the stream owners before use. The owner of this repository
  is not affiliated with any channel, source or player and does not endorse any content.
- If you own content linked here and want the link removed, open an issue and it will be
  taken out.

## Use in TiviMate

Add this URL as a playlist:

```
https://raw.githubusercontent.com/jeffersonjtf/iptv_tivimate/main/pwg.m3u
```

and this URL as the EPG source:

```
https://raw.githubusercontent.com/jeffersonjtf/iptv_tivimate/main/guide.xml
```
